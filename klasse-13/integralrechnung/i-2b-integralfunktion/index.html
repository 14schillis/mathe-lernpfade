    Die Integralfunktion

    Station 3 von 8 · etwa 5 Minuten

    Die Zuordnung, die du gerade erzeugt hast, bekommt jetzt einen Namen.

    Ia(x) = ∫xaf(t) dt

    Die Funktion Ia heißt Integralfunktion von f  zur unteren Grenze a. Ihr Funktionswert Ia(x) gibt die Flächenbilanz zwischen dem Graphen von f  und der x-Achse von a bis x an.

    Bezeichnungen zuordnen

    Wähle zuerst einen Begriff, tippe ihn dann in der passenden Zeile an.

    Beispiel zur Schreibweise

    Angenommen, es gilt ∫41f(t) dt = 5. Dann ist I1(4) = ∫41f(t) dt = 5.

    Der Funktionswert von I1 an der Stelle 4 ist also 5.

    Abschnitt 2: Der Funktionswert gibt die Flächenbilanz an.

    Warum ist a eine Nullstelle?

    Schiebe x genau auf a. Was zeigt der Integralwert dann an?

    Bewege den Regler ganz nach links.
    Bei x = a liegt zwischen den Grenzen keine Fläche.
    Ia(a) = ∫aaf(t) dt = 0 – der Punkt (a | 0) liegt also immer auf dem Graphen von Ia. Damit ist a stets eine Nullstelle von Ia.

    Station 7 von 8 · etwa 6 Minuten
    Im Bereich links von a liegt der Graph von f  oberhalb der Achse.
    aktueller Integralwert
    Ia(x)  =  0,00
    obere Grenze x = 1,50

    Schiebe x nach links über a hinaus und beobachte den Integralwert.

    Bewege den Regler nach links, bis x kleiner als a ist.
    Auffällig: Die Fläche zwischen x und a liegt oberhalb der Achse – trotzdem ist der Integralwert negativ.
    Der Grund ist die Integrationsrichtung: ∫xaf(t) dt = − ∫axf(t) dt Das ist die schon bekannte Regel vom Vertauschen der Grenzen.

    Zwei verschiedene Gründe für ein Minuszeichen

    Grund 1 · f(t) < 0

    Der Graph liegt unterhalb der x-Achse. Die Teilfläche liefert einen negativen Flächenbeitrag.

    Das war das Thema von I.2a.

    Grund 2 · x < a

    Es wird entgegen der üblichen Richtung integriert. Das Vertauschen der Grenzen dreht das Vorzeichen um.

    Die Fläche selbst kann dabei oberhalb der Achse liegen.

    Beide Gründe sind voneinander unabhängig – sie können auch zusammen auftreten.

    📝 HEFTEINTRAG

    Ergänze jetzt Abschnitt 5 (er steht auf dem Blatt vor Abschnitt 6):

    Lücke: Genutzt wird die bekannte Regel zum Vertauschen der Integralgrenzen.

    Beispiel: Ist ∫31f(t) dt = 4, dann gilt I3(1) = ∫13f(t) dt = − 4.
