    📝 DEFINITION

    Eine Funktion

    f: x ↦ ax,   x ∈ ℝ

    heißt Exponentialfunktion. Die Zahl a heißt Wachstumsfaktor oder Basis; es gilt a > 0 und a ≠ 1.

    Das Entscheidende: Die Variable x steht im Exponenten – nicht in der Basis. Warum a ≠ 1 gefordert wird, untersuchst du in Station 2.

    Fall 0 < a < 1

    📝 SICHERUNG 2A

    Für f(x) = ax gilt immer:

    • f(0) = a0 = 1 – jeder Graph verläuft durch P(0 | 1).

    • ax > 0 für alle x ∈ ℝ – der Graph liegt vollständig oberhalb der x-Achse und hat keine Nullstelle.

    • Beim Durchlaufen aller reellen x nimmt der Graph alle positiven Werte an. Deshalb ist die Wertemenge

    W = ]0; ∞[

    (gleichbedeutend mit ℝ+ = ]0; ∞[ – die Null gehört nicht dazu).

    • Die x-Achse ist waagrechte Asymptote:

    Fall a > 1

    f(x) → 0 für x → −∞

    Fall 0 < a < 1

    f(x) → 0 für x → +∞

    Kehrwertbasen – Spiegelbilder

    Station 4 von 8 · etwa 5 Minuten

    Zwei Funktionen gleichzeitig: f(x) = ax und g(x) = (1/a)x. Die Basen sind Kehrwerte voneinander.

    f(x) = ax g(x) = (1/a)x
    Eingestellt
    a =  2 Kehrwert 1/a = 0,5
    Forschungsauftrag

    Warum ist das so?

    Nach den Potenzgesetzen gilt:

    (1/a)x = (a−1)x = a−x = f(−x)

    g nimmt an der Stelle x also genau den Wert an, den f an der Stelle −x hat. Genau das bedeutet Spiegelung an der y-Achse.

    📝 SICHERUNG 2B

    Die Graphen von f(x) = ax und g(x) = (1/a)x = a−x liegen achsensymmetrisch bezüglich der y-Achse.

    📝 SICHERUNG 3

    Allgemeine Exponentialfunktion:

    h(x) = b · ax   mit   a > 0,   a ≠ 1,   b ≠ 0

    • h(0) = b · a0 = b – der Graph verläuft durch P(0 | b).

    | b | > 1

    Streckung in y-Richtung

    0 < | b | < 1

    Stauchung in y-Richtung

    • Ist b < 0, so wird der gestreckte bzw. gestauchte Graph zusätzlich an der x-Achse gespiegelt. Dadurch kehrt sich auch das Monotonieverhalten um:

    b > 0 und a > 1: streng monoton steigend
    b > 0 und 0 < a < 1: streng monoton fallend
    b < 0 und a > 1: streng monoton fallend
    b < 0 und 0 < a < 1: streng monoton steigend
